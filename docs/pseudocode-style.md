# 疑似コードの書き方ガイド（科目B準拠）

アルゴクエストの「疑似コード」表示は、IPA が定める **基本情報技術者試験・科目Bの擬似言語の記述形式** に合わせて書く。
問題を作るときは必ずこのガイドに従う（仕様書 §10.4 の記法表はこのガイドで置き換える）。

- 出典：IPA「試験で使用する情報技術に関する用語・プログラム言語など Ver.5.1」別紙2「擬似言語の記述形式（基本情報技術者試験，応用情報技術者試験用）」
  https://www.ipa.go.jp/shiken/syllabus/doe3um0000002djj-att/shiken_yougo_ver5_1.pdf
- 参考：IPA「基本情報技術者試験 科目Bのサンプル問題」
  https://www.ipa.go.jp/shiken/syllabus/ps6vr7000000oett-att/fe_kamoku_b_sample.pdf
- 記述形式（文法）だけを参考にする。**試験問題の文面・プログラムは転載しない**（仕様 §13）。

## 1. 記述形式（IPA 準拠）

| 書き方 | 意味 |
|---|---|
| `○整数型: f(整数型: n)` / `○手続名(引数)` | 関数・手続の宣言（関数を扱う問題だけで使う） |
| `整数型: x` / `整数型: x, y` / `整数型: x ← 7` | 変数の宣言（初期値つきも可） |
| `整数型の配列: a ← {3, 1, 2}` | 配列の宣言 |
| `/* 注釈 */` | 注釈 |
| `x ← 式` | 代入 |
| `手続名(引数, …)` | 手続・関数の呼出し |
| `if (条件式)` … `elseif (条件式)` … `else` … `endif` | 選択処理 |
| `while (条件式)` … `endwhile` | 前判定繰返し |
| `do` … `while (条件式)` | 後判定繰返し |
| `for (i を 1 から n まで 1 ずつ増やす)` … `endfor` | 繰返し（制御記述は日本語で書く） |
| `return 式` | 戻り値を返す |

### 演算子（優先度の高い順）
`()` → 単項 `not ＋ －` → 乗除 `mod × ÷` → 加減 `＋ －` → 関係 `≠ ≦ ≧ ＜ ＝ ＞` → `and` → `or`

### 書式のきまり（このゲームでの統一）
- 演算子は **全角**：`＋ － × ÷ ＝ ≠ ≦ ≧ ＜ ＞`、前後に半角スペース。`←` も前後にスペース。
- ブロックの中は **半角スペース2つ** で字下げする（`program.ja` も同じ字下げにする）。
- 条件式は、IPA サンプル問題と同じく日本語の述語で書く：
  `x が 5 以上` / `x が 5 以下` / `x が 5 より大きい` / `x が 5 より小さい` / `x が 5 と等しい` / `x が 5 と等しくない`
  複合条件は `(x が 4 以上) and (x が 9 より小さい)` のように括弧で囲む。
  式の中の計算（`i mod 2`、`a[i] ＋ 1` など）は記号で書く。例：`if (i mod 2 が 0 と等しい)`
- 論理型の定数は `true` / `false`。値がない状態は「未定義」。
- 配列の要素は `a[i]`、二次元配列は `a[i, j]`、要素数は `a の要素数`、商は `n ÷ 2 の商`。
- **配列の要素番号は 1 から始まる**。科目Bでは問題文で毎回明示されるので、配列を使うステージでは `notes` に「配列の要素番号は 1 から始まる。」を必ず書く。
- 宣言のない変数は使わない。変数の型は基本 `整数型`（必要なら `論理型` `文字型` `文字列型`）。

## 2. ゲーム独自の手続（フィールドの操作）

科目Bには「キャラクターを動かす」命令はないので、**問題文で説明される手続**として扱う
（科目Bでも、問題文で説明された手続・メソッドを呼び出す形式はよく使われる）。
使うステージでは `notes` に説明を書き、問題画面の処理の下に「〔手続の説明〕」として表示する。

| 疑似コード | 日本語表示 | 説明（notes に書く文） |
|---|---|---|
| `moveRight(n)` | 右へ n マス 進む | 手続 moveRight(n) は，アルゴくんを右へ n マス進める。 |
| `moveLeft(n)` | 左へ n マス 進む | 同上（左） |
| `moveUp(n)` | 上へ n マス 進む | 同上（上） |
| `moveDown(n)` | 下へ n マス 進む | 同上（下） |
| `push(x)` / `pop()` | スタックに x を積む／スタックから取り出す | ⑦で使う。戻り値のある手続は `v ← pop()` |
| `enqueue(x)` / `dequeue()` | キューに x を並べる／キューから取り出す | ⑦で使う |
| `size()` | スタック（キュー）に入っている値の個数 | ⑨で使う。関数 size() は，スタックに入っている値の個数を返す。 |
| `move(d)` | コマを向き d へ 1 部屋進める | ⑨で使う。向きは 1 上、2 右、3 下、4 左（〔説明〕に書く） |
| `room()` | コマが今いる部屋の番号 | ⑨で使う |
| `canMove(d)` | コマが向き d へ進めるか（true / false） | ⑨で使う。`while (not canMove(d))` の形で使う |
| `neighborCount(v)` / `neighbor(v, k)` | 部屋 v の隣の部屋の数／番号の小さい方から k 番目の隣の部屋 | ⑨で使う。k は 1 以上 neighborCount(v) 以下 |

## 3. 日本語表示（`program.ja`）との対応

`program.ja` は `program.code` と **1行ずつ対応** させる（行数・字下げを完全一致）。

| 疑似コード | 日本語表示 |
|---|---|
| `整数型: x, y` | 整数を入れる変数 x と y を用意する（まだ空っぽ） |
| `整数型: x ← 7` | 整数の変数 x を用意して、7 を入れる |
| `x ← 3` | x に 3 を入れる |
| `y ← x ＋ 2` | x の値に 2 を足して、その答えを y に入れる |
| `p ← q` | q の値を p に写す（q はそのまま） |
| `x ← x ＋ 1` | x を 1 増やす |
| `if (x が 5 以上)` | もし x が 5 以上なら、3行目を実行する（中の行番号を書く） |
| `elseif (x が 3 以上)` | そうではなく、x が 3 以上なら、5行目を実行する |
| `else` | x が 5 以上でないときは、5行目を実行する（2択のとき）／どれにも当てはまらないときは、7行目を実行する（3択以上） |
| `endif` | （ここで分かれ道は終わり。この先はどちらでも実行する） |
| `for (i を 1 から 3 まで 1 ずつ増やす)` | i を 1 から 3 まで 1ずつ増やしながら、4行目を繰り返す（繰り返す行の範囲を書く） |
| `endfor` | （繰り返す範囲はここまで。3行目に戻る） |
| `while (x が 10 より小さい)` | x が 10 より小さいあいだ、5〜9行目を繰り返す |
| `endwhile` | （繰り返す範囲はここまで。4行目に戻る） |
| `a[2] ← a[1] ＋ a[3]` | a の 1番目と 3番目を足して、その答えを a の 2番目に入れる |
| `return x` | x を結果として返す |
| `○整数型: f(整数型: n)` | 関数 f（整数の引数 n を受け取り、整数を返す）の始まり |
| `○f(整数型: n)` | 手続 f（整数の引数 n を受け取る）の始まり |
| `return n × f(n － 1)` | n － 1 を引数にして f を呼び出し、その結果に n を掛けた値を返す |
| `整数型: x ← f(3)` | 整数の変数 x を用意して、3 を引数にして f を呼び出した結果を入れる |

## 4. 選択肢の `code` 表現
- 位置を問う問題は作らない（科目Bに出ないため。値を問う）
- 穴埋め（Lv6〜10）：処理の行に「［a］」を書き、選択肢は空欄に入る疑似コード（`y`、`sum ÷ 3`、空欄2つは `a：p　b：t`）。空欄の記号とまぎれないよう、変数名に a・b を使わない
- 値：`x = 4` / `x = 4, y = 5`
- 配列：`a = {3, 1, 2}`（IPA の配列表記に合わせて波かっこ）
- 順序：`3 → 1 → 2`、回数：`3 回`、真偽：`true` / `false`

## 5. ヒント・解説・誤答フィードバックの書き方
- **文体**：漢字かな交じりの普通の文で書き、単語ごとにスペースを入れる「分かち書き」はしない（例「プログラムを実行し終わったときの配列 b の内容はどれか。」）。変数名・数値・式の前後だけ半角スペースを入れる（「x に 3 を入れる」）。タイトル・intro・アルゴくんのセリフ・吹き出しも同じ（ひらがなだらけにしない）。
- **日本語表示しか見ていない人にも通じる文にする。** 疑似コードだけに出てくる記号・キーワードに触れるときは、
  日本語表示の言い方を主にして「疑似コードの「←」」「「分かれ道の終わり」（疑似コードの endif）」のように両方を書く。
  場所は「3行目」のように行番号で指すのを基本にする（どちらの表示でも行番号は同じ）。
- 「右辺・左辺」「代入」などの用語は、なるべく「右側の計算」「変数に入れる」のような言い方にする（初めて出すときは言い換えを添える）。
- ヒントは3段階で、**①（無料）から具体的な手がかりを出す**：
  - ① 最初の1〜2行を、実際の値や位置で一緒に追跡して見せ、次にどこを考えればよいかを示す。
  - ② 間違えやすいポイント（更新の順番・条件の成り立ち・境界・ループの回数など）を具体的に示す。
  - ③ 答えの一歩手前まで、追跡の流れを示す（最後の確認は本人にさせてもよい）。
